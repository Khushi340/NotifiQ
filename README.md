# NotifiQ

Reliable Multi-Channel Notification Delivery Platform built using Spring Boot.

## Tech Stack

- Java 17
- Spring Boot 3
- PostgreSQL
- Spring Data JPA
- Spring Validation
- Spring Security

## Features Implemented

- User Management APIs
- User Preference APIs
- Notification APIs
- Idempotency Handling
- Global Exception Handling

## Planned Features

- Preference Filtering
- Email Delivery (Mailtrap)
- In-App Notifications
- Retry Mechanism
- Dead Letter Queue
- Admin Dashboard
- Swagger/OpenAPI
